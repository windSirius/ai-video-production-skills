# 狐久新青年体考据卡

适用狐久后续 B/C 轨。依据 GI71_EP005 用户决定：“B的卡片以后就按照这个大小”“B和C的字体都换成新青年体”“卡片的设计需要更贴合整体考据的氛围”。不追溯改写已封存旧期。

## 固定资产

- 模板：`assets/foxjiu-evidence-card-v1.json`，样式 `foxjiu-ink-archive-xinqingnian-v1`。
- 字体：文悦新青年体 J W8，文件 `WenYue_XinQingNianTi_J-W8.otf`，SHA-256 `bf7182e6da0d84551023edfbb4242280752902bd06807a156050122df8875a70`。当前安装在 `~/Library/Fonts/`；不随 skill 复制商业字体文件。
- 制作方新增的标题、正文、出处与推测标签全部使用该字体、简体中文；原生截图和 PV 字幕不重写。缺字必须显式处理，不能偷偷调用黑体等备用字体。关系箭头和加号可用模板中的矢量线条绘制，清单记录 `vector_symbols`。

## 尺寸契约

下表坐标基于 2560×1440，720p 审片按 0.5 等比缩放。返修优先保留输入清单中实际外框，不能换字体后自动缩卡。

| 版式 | x / y | 宽 × 高 | 使用场景 |
| --- | --- | --- | --- |
| B_native | 96 / 830 | 2368 × 490 | 引文配原生截图 |
| B_transcription | 96 / 816 | 2368 × 504 | 原文转录或较长短引文 |
| B_portrait | 96 / 640 | 2368 × 680 | 花散里式人物图文证据 |
| C_relation | 96 / 1110 | 2250 × 200 | 少量关系提示 |

采用墨色底、暖白正文、暗金边线和朱砂重点，形成档案阅读氛围。层级保持“短标题—重点原文—出处”；不添加虚构官方印章、档案编号或未经核实的出处。推测必须保持推测标识，神话转述不能装成游戏原文。

长文保持可读字号：先优化断行；不足时拆页并重新核对时长与审批范围，不能无限缩字。证据内容的实质改写另行核对，不因样式返修改掉原文条件。

## 实施和验收

1. 经 resolver 分配新 `tracks/vNNN`，拷贝样式快照；保留旧版文件和审批。
2. 用 `scripts/render_evidence_cards.py --cards INPUT/cards.json --output-dir NEW/B --font FONT --style STYLE_SNAPSHOT` 分别生成 B/C。依赖 Pillow；字体 cmap 检查使用 Python 标准库。
   输入是 JSON 数组，每项保留 `id`、`track`、`title`、`body`、`source_label`、`start_frame`、`end_frame` 和证据字段。`original` 是原图的 `{path,sha256}` 或 null；已有 `geometry`/`alpha` 用来核对旧版外框，新卡用 `layout` 选择上表版式。字幕编号和其他证据字段原样传递。
3. 对每张卡核对标题/原文/出处、起止整数帧、证据原图 SHA 与原版一致；返修前后 alpha 外框一致。检查缺字、溢出和全帧纯绿背景；记录实际字体及模板 SHA。
4. 将所有卡叠在实际 A 画面上，检查头/中/尾、最长引文、出处、人物图文卡、C 轨关系符号，以及每个出入点 `-1/0/+1`。完成后才能写实际检查结论；机器排版检查不冒充用户可读性验收。
5. 用户通过内容但要求字体/设计调整时，保留未改的 A 和选曲审批。完成新 B/C 及已授权的全长整合候选后一起展示，允许用户一次审完；变更后的字节不能沿用旧 B/C 的审批，也不能提前视为正式渲染通过。已展示候选可在满足总控阶段条件后再登记，真实展示时间与 SHA 不变。

本样式的几何与字体是复用默认值；新题目只替换有依据的正文、原图和出处。新版视觉仍需实际审看，不用模板合格替代本期检查。
