# 语义断句

字幕边界和画面换镜是两件事。字幕先按听觉和语义切分；下游再依据项目的剪镜规则决定是否换镜。

## 断句

- 主语尽量和谓语留在同一条；
- 动词与必要宾语、补语不要拆开；
- 成对逻辑在相邻字幕中仍要能听懂；
- 不让“但、而、所以、因为、以及、的、了、着”意外独占一条；
- 人名、地名、书名、固定术语、日期和数字单位保持完整；
- 引文保留开合关系，旁白引入语与完整引文可以分成两条；
- 刻意短拍可以短，但不能只是机器切碎的残句。

## 换行与标点

SRT 默认保留一个逻辑文本行，由下游排版决定视觉换行。只有用户时间轴本来包含换行，或最终预览证明自动换行破坏短语时，才加入手动换行。

末尾标点、问叹号和引号规则读取项目 style JSON。不要把某一期字体、坐标、字数或标点习惯写成全局硬门。

## 审计

最终字幕应当：正典词面恰好覆盖一次、相邻重复为零、空条目和标点独占为零、引号成对、时间单调且时长为正。长条目和高 CPS 进入人工复核，不自动拆分。
