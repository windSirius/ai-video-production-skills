# 作者声音与论证压缩

作者声音来自取舍和判断，不来自固定反问、平均段长、密集金句或“人味词”。

整稿创作、重写、压缩和整体审校时必须执行本页。先解决承诺、结构与推导，再处理词句；以下要求来自实际稿件复盘，不把某一期的温柔气质、人物弧线或篇幅变成所有选题的模板。

## 标题承诺与正文答案

把标题、开头问句和结尾答案并排写出，核对它们谈的是同一对象、同一范围和相称的确定性。“一个听众的感受”不能未经解释变成“整个世界被改变”；“重新”需要此前失去的状态，“终于”需要此前未达成的过程。这些词不是禁词，使用时须能指出依据。

开头可保留大胆判断，但随后应落到具体画面、原文或反常处，让观众知道要追踪什么。不要连续用几个同义问句延迟进入内容。没有能力变化的证据，就不能用治愈、复活等更大承诺代替对画面含义的解读。

## 每段是否有新内容

草稿完成后，检查每段新增了什么：事件、原文、因果、后果或判断。若一段既没有新内容，也不能帮助观众理解前文、引出后文或完成必要的情绪转折，便应删除。前文出现过的内容再次出现时，必须产生新的含义，才算真正的照应。

把反复使用同一证据、同一解释的段落放在一起比较。先合并复述，再补缺失的解释，最后处理连接词。例如“女孩进入花海、两人同框、水下多了一个参与者”大体说明同一变化；不应拆成三次递进。解释完成以后，应进入新的原文、人物处境或疑问，而非换几个抽象词再解释一次。

安排关键背景和人物矛盾时，检查观众此时为何还要听下去。可以为悬念延后答案，但不能让长期复述替代推进。删除人物专名后几乎适用于任何角色的段落，需检查是否缺少本期特有的行动、原文或后果；通用经验若确实帮助理解则可保留。

## 心理推断与证据范围

分别标明剧情发生了什么、镜头怎样表现、作者怎样解读、人物内心发生了什么；四层可以相接，不能自动互证。

- 镜头追随一个听众，支持对叙事视角的讨论；要证明歌者平等对待别人，还需人物行动或台词。
- 听众进入花海，可以支持投入音乐的画面解读；歌者另有寻找心声的困惑，不等于这次演出已使她找回自我。
- 心理常识能帮助提出解释，但不是新增剧情证据。发现中间缺口时，补可定位依据，或收窄为现有材料支持的判断。“在我看来”不能为后文所有内心描写提供通行证。
- “希望唱得更好以留在剧团”压缩为“希望能够唱歌”，改变了能力程度与目的。转述要保留这些范围；两段材料出现女孩，也不能在身份未明时擅自合并或确认是不同的人。

研究记录保留缺口与竞争解释；正文通过准确命题和自然推测口吻连续展开，遵守已有反证位置规则，不新增逐段免责声明。

## 情绪与结尾

找出本期真实存在的处境变化、未解疑问和人物行动，让它们产生好奇、担忧、理解或释然。无需每篇完整经历这些情绪，也不为了起伏硬添悲剧、拯救或成长。让润喉糖、练习、继续演唱等已知行动承担情感作用，不连续宣布“温柔、震撼、动人”。

结尾完成一次连贯收束：回应开场，再由本期行动及具体后果留下余味。检查是否先总结关系、再谈普遍道理、又重讲证据、最后才落意象；重复收尾应合并，不等于只能有一段。回扣“回信”等已有意象时，不再补写未经证明的人物心理转变。升华不要求主题宏大，但应与本期人物不可分离，保留狐久固定落款。

## 排版与听觉节奏

一段承载一项完整的小推理或必要的情绪变化，证据与紧接的解释不为版面整齐而拆散。避免每段都长成“转场提示—数句说明—一句意义”的同一形状；长短服从内容，不设平均段长或句数指标。

逗号标记语义与必要重音，不在每个主语后默认停顿。标注稿在段落旁放证据定位、解释边界和可执行画面，纯文本保持干净；不能把全部定位责任推给外部表格。论证映射按实际判断填来源，落款不需要假挂证据编号。文字顺畅不等于实际配音断句通过，朗读与音频试听分别如实记录。

## 整稿审读记录

沿用本期已有审校说明及 `editorial_submission_v2` 支持的引用方式，不新造机器字段。实际说明至少覆盖以下内容，可与已有逐段表合并，不机械增加文件：

1. 标题、钩子、结尾答案的对照，以及预设或范围有无修正。
2. 逐段新增内容或必要作用；重复段组的合并、保留理由；关键人物问题为什么在该位置进入。
3. 关键推导的来源、判断层级和中间依据；补证据或收窄结论的位置。确无此类问题时也说明检查了哪些判断。
4. 措词、事实范围及段内承接的修改前后；排版与停顿的处理；情绪变化由哪些行动支撑。
5. 结尾是否重复收束、升华是否来自本期内容；新写示例是否再次出现旧问题；实际朗读或试听的完成情况。

审校顺序：先承诺与结构，再事实与推导，接着措词与衔接，最后节奏、情绪和收束。不能只填 PASS，也不能把关键词计数当成质量结论。修订例句本身同样要检查重复与越界；旧批准不使例句免检，新规则不追改已冻结历史版本。

## 证据如何取舍

- 能够改变核心结论的硬证据，应写进口播，并紧跟它所支撑的判断；
- 反证先在研究与审校中用来校准结论；狐久推断类正文不逐段插入反证或免责声明。确需口播的限定集中到结尾一小段，具体执行 [SKILL.md 的连续叙事规则](../SKILL.md#狐久推断类口播连续叙事硬规则)；
- 只能提高可信程度的旁证，可放进画面、简介或研究附录；
- 足以独立成为另一个问题的支线，留作下一期。

## 不设删除比例

不要求另存一份机械的“删除稿”，也不规定必须删 20%–35%。最好的版本不是最短，而是删掉任何一段，都会伤到叙事或论证。字数和时长以项目开始时与用户确认的要求为准。

## 去 AI 腔

同一判断不要依次换成“规则、可能性、结构、系统”再说一遍。原文、直白解释和类比只保留最有效的一两种；观众已经听懂，便不再添加第三种说法。各段不必拥有相同的长度、问句和情绪。结论说清以后，转入人物后果与收束；不因为审校做过反证，就在口播中重新展开。

精简时保留承担真实关系的“而、也、才、却、因为、于是”等词。论证段要在段内持续引导，不能只在段首加承接、随后平列结论。狐久旁白不用“有分量、多了一层分量”等万能评价；写清关键细节、核心问题或具体影响。完整操作与语境例外见 [措词手册第三、五、九节](traditional-chinese.md)，不以衔接词配额或关键词清零代替审读。
