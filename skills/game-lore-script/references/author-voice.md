# 作者声音与论证压缩

作者声音来自取舍和判断，不来自固定反问、平均段长、密集金句或“人味词”。

## 每段是否有新内容

草稿完成后，检查每段新增了什么：事件、原文、因果、反证、后果或判断。若一段既没有新内容，也不能帮助观众理解前文、引出后文或完成必要的情绪转折，便应删除。前文出现过的内容再次出现时，必须产生新的含义，才算真正的照应。

## 证据如何取舍

- 能够改变核心结论的硬证据，应写进口播，并紧跟它所支撑的判断；
- 能够阻止结论说得过满的反证，也应写进口播，但要简短处理；
- 只能提高可信程度的旁证，可放进画面、简介或研究附录；
- 足以独立成为另一个问题的支线，留作下一期。

## 不设删除比例

不要求另存一份机械的“删除稿”，也不规定必须删 20%–35%。最好的版本不是最短，而是删掉任何一段，都会伤到叙事或论证。字数和时长以项目开始时与用户确认的要求为准。

## 去 AI 腔

同一判断不要依次换成“规则、可能性、结构、系统”再说一遍。原文、直白解释和类比只保留最有效的一两种；观众已经听懂，便不再添加第三种说法。各段不必拥有相同的长度、问句和情绪。结论说清以后，只保留能够修正它的后果或反证。
