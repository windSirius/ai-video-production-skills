# 事实与版本权威

> **历史写稿参考。** 本文保留旧结构与术语；当前写稿和冻结规则以 [game-lore-script](../SKILL.md)、[作者语言](../references/author-voice.md) 和 [证据权威](../references/evidence-and-authority.md) 为准。旧文中的章节编号不再对应现行 Skill。

## 1. 事实证据层级

从强到弱依次为：游戏内正式文本与画面、官方网页或节目、可复核的官方宣传物、明确标注来源的可靠数据库、二手整理、推测与二创。高层证据与低层整理冲突时，以高层为准；页面存在分页、章节或卷册时，必须逐页核对。

每个关键论点都要能回到一个可定位的原文、截图或时间码。若只能找到二手文本，正文必须显式降级，不得把转述写成官方明示。

## 2. 文本权威层级

1. 用户明确确认的最终稿或最终字幕；
2. `口播纯文本.md` 与绑定它的 `script_manifest.json`；
3. `segments.json` 中的 canonical text；
4. Manuscript Match 或 ASR 结果；
5. 为合成发音准备的 `generation_text`。

ASR 用于发现遗漏、重复、错序和可疑读音，不负责改写正典专名。`generation_text` 只解决合成器读音，不得进入字幕、封面或考据引用。

## 3. 版本冻结

每次正式交接都记录文件 SHA-256、修改时间、正文字符数与状态。新版本不得覆盖旧版；使用 `v1 / v2 / final` 或带时间戳目录，并写清哪一份是当前权威。若音频只重做个别段落，更新音频清单与段落哈希，不要把旧候选误当最终母版。

## 4. 下游约束

- 配音按正典纯文本分段；读音代理另存。
- 字幕以正典文字校对，以最终音频决定时钟。
- A/B/C 轨从画面锚点和证据表取材，不得反向创造稿中不存在的事实。
- 封面标题可压缩表达，但不得把推测升级成定论。
