# 狐久风格拆解（DNA 样本库）

> **历史写稿参考。** 本文保留旧结构与术语；当前写稿和冻结规则以 [game-lore-script](../SKILL.md)、[作者语言](../references/author-voice.md) 和 [证据权威](../references/evidence-and-authority.md) 为准。旧文中的章节编号不再对应现行 Skill。

从既有成稿中提炼的可复用模式。写稿时对照此处的**真实句式**，而非泛泛的"风格描述"。

## 1. 开场三件套：假设反问 + 否定性原文 + 张力

结构永远是：一句「如果……呢？」→ 一句游戏原文（否定主角）→ 点破反差。

样例：
- 洛恩：「如果一个普通人的平凡，就已经值得被铭记呢？」+「迟钝、弱小，不堪一击的……凡人。」
- 桑多涅：「如果『心』这种东西，要等到一个人学会告别之后，才能真正成熟呢？」+「与人不同，机关是没有心的。」
- 姬子（本项目）：「如果一个人的憧憬，从最初那一颗种子开始，就是别人替她种下的呢？」+「对作品倾注情感，这也是『爸爸』多年以来的坏习惯了。」

注意：开场位置的意象必须钉在具体实物/动作上（见 SKILL.md 二·意象先锚地），省写意象只用于后文回收。

## 2. 承认大众印象，再掀翻

- "很多人看完这次千灵节，记住的是那些名场面……好笑吗？确实好笑。但如果只把它当成一出回归喜剧，那就太可惜了。"
- "很多人看完这次传说任务，对洛恩的观感恐怕也差不多——这角色，怎么不太『爽』？"
- 套路：先给读者一个台阶（我知道你第一眼看到的是什么），再说"但真正的东西在底下"。

## 3. 推测明码标价（泼冷水话术）

- "但我要先泼盆冷水：雷内这个角色，剧情里干的事并不是笛卡尔的哲学……"
- "我个人的推测是——比起那句怨恨，它更可能听到的，是那句……"
- "这不是我在抒情，是游戏给的细节。"
- 规则：凡是从原文往外延伸一步的判断，都先自己标出"这是推测"。

## 4. 成组镜像细节（而非排比）

桑多涅篇的高潮，是把主题拆成"第一组……第二组……第三组……第四组……第五组"的镜像细节逐一合拢；
本项目姬子篇同款——姬子的告别，是把素子十五年前的台词一句句重念，列成五组官方明示的对照。
- 写法：找到剧情里"同一结构出现两次/多次"的地方，编号列出，让呼应自己浮现，而不是用形容词去夸它感人。

## 5. 概念辨析（狐久最爱的思辨动作）

- 平凡 vs 平庸（洛恩篇）：承认局限 vs 幻想抹掉痛苦的捷径。
- 第一次出生 vs 第二次出生（桑多涅篇）：世界给的生命 vs 自己选择的生命。
- 复制 vs 传承（姬子篇）：同一个东西再做一遍 vs 有人接住它、走远、再原样交给下一个。
- 写法：把主题浓缩成一对最小对立词，全篇围绕它推进。
- 变体·对照组：给主论证安排一个反例（如"拼贴也能是搭建"），让结论不一边倒，高潮处的"刻意"更有说服力。

## 6. 现实映射（可选技法，仅用户明确要求时用）

后段的默认写法是**上价值收束**：一到两句点明本期素材本身的价值，再进入结尾回扣（见 SKILL.md 四·第4条）。
以下映射话术仅在用户明确要求"拉回现实"时使用：

- "讲到这，可能有人觉得，这是个游戏角色的故事，离我挺远。不远。"
- "我们大多数人，也不会成为故事里最强的角色。"
- 把角色困境映射到真实人群：被当成"另一个人的延续"养大的人、怕失去所以不敢开始的人、被教育"必须牺牲/交换"的人。

## 7. 结尾回扣 + 金句（可选） + 固定签名

- 回扣开场意象：桑多涅篇结尾回到"被扔进海里的娃娃"；洛恩篇回到墓志铭与泡泡糖；姬子篇回到"作品"一词与海滩那句台词。
- 金句可选；若写必须扣母题，且意象已在前文锚地：
  - "机关有没有心，从来不看它由什么构成——只看它选择留住什么。"
  - "凡人，也有凡人要打的架。打赢这场架，不需要变成怪物。"
  - "作品做不到这件事——作品不会把自己的台词，一字不差地交给下一个人。"
- 固定签名（一字不改）：**「那，以上，我是狐久，我们下期视频再见。」**

## 8. 语言手感清单

- **句子的呼吸方式（最高优先级）**：基本句是逗号流水长句——一句话走完一个完整推理弧（背景、原因、结论可以全在一个句号内），句号只落在论证节点。短句只用于急刹和金句落点。判据：写完一段自问"这是记下来的说话，还是念出来的文章？"
- **短句分区**是呼吸方式在转场位的应用：转场承接位一律用补全因果与主语的完整句。判定标准：转场处省字是偷懒，爆点处省字是打拍子。
- **术语三级降落：原文→人话→玩家类比。** 换挡动作明说（"用人话翻译一下就是""就像你开一把游戏……"）。只给精确定义、不落到玩家经验的，视为没讲。
- **保留口语冗余**："又或者说""换句话说""也就是说"是听觉缓冲区，不按书面标准砍。铺垫超过一节时，当面跟观众结账。
- 动词优先，少形容词；避免"震撼""泪目""封神"这类营销词。
- 禁用一切对比反转模板句："不是A，而是B""不是A，是B""与其说……不如说……"——AI 味最重。改用直陈：先给结论，再补原因/原文；需要对照时用编号镜像组。
  - 反面（别写）：「素子不是姬子的复制品。素子是……」「引擎不是被修好的，是被相信点燃的。」
  - 正面（这样写）：「素子身上有一样姬子缺的东西，被单独拎出来做成了人。」「那台引擎，等的从来是一个非要出发不可的人。」
- 少用排比；需要并列时用编号镜像组代替。
- 腔调校准：成稿后按 SKILL.md 二·反欧化六条单独跑一遍，判据是"像不像在跟观众说话"，不是语法纯度——被字句、长定语在口语流水里自然出现的，不算病。
- 口播稿是画面解说词：每句都要能对上素材数据里的一个画面，素材里没有的画面/台词不写。
- 允许冷幽默与轻微自嘲，但不喧宾夺主。
- 原文引用一律「」，逐字。
