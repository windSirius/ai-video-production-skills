## 一、〔第一幕小标题：立命题〕

〔素材 时间戳〕

〔用原文直引展开反派/处境的命题。每个论点后跟「原文」。〕

〔本幕题眼原文，建议逐字打屏：「……」〕

〔一句分析，点出主角争的到底是什么。〕

〔埋一个后文要回收的钩子，并明说"记住这个钩子"。※若后续删段，务必回来检查此钩子是否悬空。〕

## 二、〔第二幕小标题：溯源〕

〔素材 时间戳〕

〔顺时间轴讲清"主角为什么会这样"。关键因果处放慢，标注"这里是全篇最关键的一处因果"。〕

〔成组镜像细节：第一组……第二组……〕

〔概念辨析：〔A〕 vs 〔B〕。〕

〔可选·对照组：给主论证安排一个反例，让结论不一边倒。〕

## 三、〔第三幕小标题：应答/反转〕

〔素材 时间戳〕

〔回收第一幕的钩子。用原文完成命题的反转或应答。payoff 落地的同一句里可接续下一问，保持悬念链不断档。〕

〔若有官方自己剪在一起的镜像台词，编号列出——这是最硬的爆点，给足节奏。〕

〔待核验项：〔如有，标出并提醒成稿前回原文确认〕〕

## 四、上价值收束（默认）

〔一到两句直接点明本期素材本身的价值，作为论证的收口。
例："原神值得细看的地方，远比主线台词多——连曲名和歌词，都经得起逐字考据。"〕

〔可选·现实映射段（仅用户明确要求时写）：把角色困境映射到真实人群——
被当成别人的延续 / 怕失去 / 被教育必须牺牲……逐类给一句解压的话，引用角色原文作答。〕
