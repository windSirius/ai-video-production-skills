# 游戏剧情考据口播稿（狐久风格）

作者署名「狐久」，做星铁/原神等游戏的剧情考据长视频。风格写死，稳定复现，不要即兴发明。

---

# ■ 第一原则：写中文，不写译文腔

**这一条压倒本文档其余一切规则。风格、结构、密度、金句，全部让位于它。**
**这一条不通过，稿子不许交。**

## 为什么它排在第一

这套方法翻过两次车，两次都不是文笔问题，是**根本没在写中文**：

- 第一次：教科书式欧化词表（作为／由于／进行／之一／被…所）全篇不到十处，数据干净，
  念出来仍是论文腔。**因为欧化不在词表上，在句子骨架上。**
- 第二次：文档里明明写着「长定语拆流水」，写稿时照样违反。
  **因为那条被写成了"检查标准"，只在自检时才想起，动笔时根本没进入决策。**

所以这一版写成**动笔时必须执行的动作**，并配否决线。

## 一句话病理

> **译文腔 = `长名词短语 + 是 + 长名词短语`**
> **中文 = `谁 + 干了什么 + 了`**

考据内容天然名词密集（纪年、氏族、头衔、书名、脚注号）。
为了把这些塞进句子，人会本能选名词化句式，**因为它装得下**。
代价是装得下、念不动。

**正解不是压缩，是加通道**：把信息分布到多个短句，用动词串起来。

## 中文长什么样（正面样板，照着写）

| 特征 | 说明 | 例 |
|---|---|---|
| **话题优先** | 先把话题抛出来，再评述。不必凑主谓宾 | 「这本书啊，纪年是七年一纪」 |
| **短句成链** | 一个意思一个小句，逗号串起来 | 「他回来了，一句话没说，在林子里想了很久」 |
| **动词密集** | 每个小句都要有实义动词 | 「翻、捋、定、拆、扎、烧、收」 |
| **修饰后置** | 先给主干，再补细节 | 「一座沉进湖底的城，等着人重新看见它」 |
| **语气落地** | 了／啊／呢／吧／嘛／罢了 | 「找茬的由头罢了」 |
| **意合连贯** | 不靠连词也能连贯，少用"由于…因此" | 「名字太长，记不住没关系」 |

## 动笔时的三个动作（不是写完再查）

**动作一 · 先定动词，再造句。**
每写一句之前，先问「这句的实义动词是什么」。
定下动词再往上挂主语和宾语。**动词只有"是"的句子，不许出生。**

**动作二 · 修饰一律甩到后面。**
想写前置定语时立刻停手，把它拆成主干后面的独立小句。
写「这一座沉下去、等着重新让人看见的城邦」之前就该拦住自己，
写成「一座城，沉进了湖底，等着人重新看见它」。

**动作三 · 每写完一段，出声念一遍。**
凡是需要换两次气才读得完的句子，当场拆开。凡是要回头看第二遍才懂的，当场重写。
**这个动作不能留到自检阶段，必须贴着写作进行。**

### 整段改写示范

**原（6 个"的"，论文腔）**
> 如果说至冬的历史，甚至可以追溯到提瓦特最早的文明呢？今天这期视频，我将从《苍星妖灵史略》出发，
> 为各位玩家整理一下目前已知的、至冬相关的历史。而做考据的第一件事，是先有一把能量的尺子。

**改（1 个"的"，动词流）**
> 如果至冬的历史，能一路倒推到提瓦特最早那批文明呢？
> 这期我们就翻一本书——《苍星妖灵史略》，把至冬现在能查到的事，从头捋一遍。
> 捋之前得先干一件事：把尺子定下来。

动词密度：倒推、翻、捋、定。名词短语全拆成了动作。

## 否决线（跑不过不许交稿）

```bash
python3 - <<'EOF'
import re
t=open("稿件.md",encoding="utf-8").read()
b=t.split("## 三、口播稿正文")[1].split("## 四、标题池")[0]
# 只取口播行，排除锚点/表格/标题/旁注/引文行
L=[]
for ln in b.split("\n"):
    s=ln.strip()
    if not s or s.startswith(("〔","|","---","#",">")): continue
    if re.fullmatch(r'（[^）]*）',s): continue
    if s.startswith("「") or s.startswith("『"): continue      # 引文豁免
    L.append(re.sub(r'〔[^〕]*〕|（停[^）]*）|\*\*|\*|`','',s))
join="".join(L)
de3   = sum(1 for s in L if s.count("的")>=3)
judge = len(re.findall(r'是(一种|一个|一件|一场|整个)|的第一件事，?是|本身就是一', join))
frame = len(re.findall(r'的地方|的事情|值得[一-龥]{0,2}说|这个[一-龥]{1,3}本身|各位玩家', join))
longd = len(re.findall(r'[一-龥]{9,}的[一-龥]{2,4}(?=，|。|$)', join))
de_rate = join.count("的")/max(len(join),1)*100
print(f"的字≥3的句 {de3}（限 0）")
print(f"判断框     {judge}（限 0）")
print(f"冗余框架   {frame}（限 0）")
print(f"9字以上前置定语 {longd}（限 0）")
print(f"「的」密度 {de_rate:.1f}%（限 ≤3.0）")
print("PASS" if de3==0 and judge==0 and frame==0 and longd==0 and de_rate<=3.0 else "*** FAIL：回去重写，不许交 ***")
EOF
```

**五项全零/达标才算通过。任何一项亮红，回去重写那些句子，不许用"考据内容名词多"当理由。**

## 预先堵死四种自我开脱

1. **"考据内容名词密集是客观的"** —— 名词密集不等于句子必须名词化。
   同样的信息，拆成三个动词小句照样装得下，而且更清楚。
2. **"这是引用原文，必须逐字"** —— 逐字引用交给画面。口播转述。见第二原则。
3. **"流水长句是狐久风格"** —— 流水长句指**用逗号串起来的一串动作**，
   不是一个塞满定语的长名词短语。两者形似而质相反。
4. **"改了就没那个味道了"** —— 味道来自节奏和判断，不来自定语层数。
   上面每一组改写，改完的版本都更有劲。

# ■ 第二原则：给耳朵写，不给眼睛写

观众听不到排版、看不见引号、不能回头重读。

1. **同形异音自查** —— 搜 `能量 重 行 长 还 少 更 量 藏 数 分 干 血 率 相 系 便 中 空 强 差 当`，
   凡能被念成另一个音的一律换词。
   **翻车实例**：「先有一把**能量**的尺子」（本意"能·量"），观众百分百听成 néngliàng，
   且这句在开场第 7 条，头一分钟就崩了信任。
2. **一句一个陌生名** —— 音译名出现前给身份标签，出现后给用途；用不上的不进口播，进字卡。
   **翻车实例**：「穆斯季斯莱沃洛、尼约默罗德、达洛格莱德、切纳雷卡四大氏族」四名连轰，
   **能听懂的版本还放在后一句**。正解：「他带来了四支氏族：熊、牛、狼，还有一支水妖。
   名字都特别长，记不住没关系。」
3. **引文分流** —— 超过 20 字或带长定语/倒装的原文，**口播转述 + 画面高亮原文**，不照念。
   保留原文最有味道的那个词（如"无比顺滑"），其余转述。
   **考据严谨性由画面担，听觉流畅度由口播担。两者不挤在同一通道。**
4. **默读全篇** —— 要回头看第二遍才懂的句子，全部拆开。

# ■ 第三原则：三条铁律

- **人称一律"我们"**，叙述层零"你/你们"（举例代入也用"我们"）。唯一例外：引文内逐字保留。
- **「东西」一律不用** —— 它是"没想清楚指代什么"的标记。
  接过来的东西→那份遗产；研究出来的东西→产物；被造出来的东西→一件造物；再收东西→再收权。
- **禁用对比模板句** —— "不是A而是B""不是A，是B""与其说…不如说"。改直陈，或用编号镜像组。

# 一、什么时候用 / 不用

用：游戏剧情考据/解析视频的口播稿、叙事思路、标题、开场钩子；或据用户给的视频/台词成稿。
不用：商业带货、非剧情向脚本、纯攻略数值。

# 二、底层信念

**狐久不写爽文，写主体性与思辨。**

- 主题落在"人怎么面对自己的处境"——被定义、被牺牲、平凡的上限、心是造出来的还是选出来的。
- **证据优先于抒情。** 没有原文支撑的推论，要么标推测，要么不写。
- **金句可以燃，结论必须稳。** 拒绝空泛抒情，拒绝堆排比。
- **句子的呼吸**：基本句是逗号流水长句，一句走完一个推理弧，句号只落在论证节点；
  短句只用于急刹和金句落点。**注意流水句 ≠ 长名词短语，见第一原则。**
- **转场关节禁电报腔**：承接句补全因果与主语。转场省字是偷懒，爆点省字是打拍子。
- **意象先锚地再省写**：无前置语境处（尤其开场前30秒）必须钉在具体实物或动作上。
  反例："罪留下了。太阳，被拿走了。" 正例："制作组留下了罪，把能化掉罪的太阳，从句子里删走了。"
- **术语三级降落：原文→人话→玩家类比**，换挡动作明说。
  **这条同样管人名、地名、引文**，漏了后者就是第二原则的翻车。
- **保留口语冗余**："又或者说""换句话说"是听觉缓冲区。
- 后段以**上价值收束**结束论证，再进结尾回扣。现实映射段仅用户明确要求时写。

**补充排查线索**（第一原则之外）：①"被"字句限量——被天理毁掉→**让天理砸没**，
被长枪贯穿→**死在长枪之下**，被使用→**为人所用**，被他拒绝→**遭他拒绝**（引文内保留）；
②数量词冗余——"有一种推测"→"有个推测"（"一个字都没写""一头熊"这类自然量词位保留）；
③抽象名词宾语改动词句；④"这件事/的东西"套壳删除。

## ★ 口播稿是画面的解说词

- 素材数据 = 成片里真实能用的画面，是硬约束。每句口播都要能对上一个具体画面。
- **素材里没有的画面和台词，一律不写进稿子。**
- 叙事顺序顺着素材时间轴走。
- 素材未到位时锚点按类型标注（`〔素材｜书籍界面 · 脚注140 高亮〕`），文末附素材需求清单表。

# 三、工作流

先读 [事实与版本权威.md](reference/事实与版本权威.md)。事实来源、稿件正文、配音代理文本、ASR 与字幕各有不同职责；任何方便发音的替代写法都不得反向污染正典稿。

### Step 0 · 素材与台词转写
逐条带时间戳、标说话人。无字幕文件时用 ffmpeg 抽帧裁字幕区、二值化 IoU 去重后拼图识别；
长视频（>30min）先 `-skip_frame nokey` 抽关键帧做缩略图总览定位，再细扫目标区间。
广告段单独标出剔除。**只用转写到的原文，不凭记忆补台词。**

同时建立 `evidence_ledger.tsv`：每条关键结论至少记录 `claim_id / 原文 / 来源路径或链接 / 页码或时间码 / 证据等级 / 核验状态`。网页有 `volume`、`chapter` 或分页时，必须逐页看完，不得只看入口页。

### Step 0.5 · 范围校准
独立考据点超 12 个时先确认：①范围 ②切入重心 ③成片时长。
总览稿策略：每组块只取最强 2–3 个案例展开，其余点名带过。

### Step 1 · 立主题
核心矛盾必须：①可证伪 ②原文兜底 ③落在主体性/思辨层。主题不成立就别往下写。
参考视频型选题：主题必须比参考视频更进一层。

### Step 2 · 叙事思路
按第四节结构搭骨架，每段标：要讲的点 / 情绪目标 / 证据支点（含分级）。标爆点位与待核验点。

### Step 3 · 成稿
**动笔时同步执行第一原则的三个动作。** 段前加剪辑锚点。
停顿写进稿子：`（停）``（停两拍）``（停足三拍，不要接话）`。结尾固定签名。

同步导出两份互不混淆的文本：

- `口播稿.md`：保留标题、锚点、证据等级、素材需求与旁注；
- `口播纯文本.md`：只保留真正念出口的正典文字，供 VoxCPM、字幕与覆盖审计使用。

两份正文去除结构标记后必须逐字一致。若配音为了读音临时把“槲寄生”写成“胡寄生”，只记录在 `generation_text`，正典纯文本和字幕仍写“槲寄生”。

### Step 3.5 · 三道机检（禁止估算，数字必须实测）

**第一道 · 第一原则否决线** —— 优先运行 `python3 scripts/audit_lore_script.py 稿件.md`；五项达标才算过，FAIL 就回去重写。上方单行脚本仅作无依赖备用。

**第二道 · 铁律检测**
```bash
python3 -c "
import re;t=open('稿件.md',encoding='utf-8').read()
b=t.split('## 三、口播稿正文')[1].split('## 四、标题池')[0];c=lambda p:len(re.findall(p,b))
print('东西',c('东西'),'|你',c('你'),'|对比句',c('不是.{1,12}而是|不是.{1,10}，是|与其说.{1,15}不如说'))"
```
"东西"与对比句必须 0；"你"的残留须逐处确认落在引文内。

**第三道 · 时长实测** —— 只统计真正念出口的字，剔除锚点、停顿标记、旁注、表格、markdown：
```bash
python3 -c "
import re;t=open('稿件.md',encoding='utf-8').read()
b=t.split('## 三、口播稿正文')[1].split('## 四、标题池')[0];o=[]
for ln in b.split('\n'):
    s=ln.strip()
    if not s or s.startswith(('〔','|','---','#','>')): continue
    if re.fullmatch(r'（[^）]*）',s): continue
    o.append(re.sub(r'〔[^〕]*〕|（停[^）]*）|\*\*|\*|\`','',s))
n=len(re.sub(r'\s','',''.join(o)));print(f'口播 {n} 字 → {n/400:.1f}–{n/350:.1f} 分钟')"
```
**别拿带锚点的总字数除语速**（曾把 29 分钟误报成 20 分钟）。
超时 20% 以上时给「按现状发 / 逐节砍 / 拆两期」三选项，附逐节字数表标明哪几节是骨头。

### Step 3.6 · 听觉体检
逐项过第二原则四条：同形异音、一句一个陌生名、引文分流、默读。

### Step 4 · 标题池 + 钩子
标题 3–4 个，覆盖题眼/情感/悬念/"如果…呢"四条弦，首选放最前标注理由。
格式：`主角：一句戳中主题的话【栏目名考据】`（原神惯用"障眼法考据"）。钩子给 2–3 个备选。

### Step 5 · 自检
逐条走第六节清单。删过段落的，全篇搜指向被删内容的引线，悬空的当场处理。

### Step 6 · 冻结与下游交接

用户确认稿件后写 `script_manifest.json`，至少绑定 `口播稿.md`、`口播纯文本.md`、证据表的 SHA-256，并把该版本标为 `canonical`。后续若用户提供最终字幕，以最终字幕为成片时钟权威，但不得据此悄悄改写已经确认的论点；任何文字差异都要另列变更表。

交接包至少包含：正典纯文本、发音表、专名表、画面锚点、证据表、标题池、钩子备选、未核验项和素材缺口。

# 四、叙事结构（写死）

1. **开场钩子**：「如果……呢？」假设反问 → 一句游戏原文（「」引）→ 用**别人对主角的否定性评价**立张力。
   例：「不堪一击的凡人」「机关是没有心的」「你只是我的作品」「神圣的血脉——意义不明」。
2. **第二拍·承认再掀翻**：先承认大众印象，再一句掀翻，抛出真问题。
3. **中段·证据推进**：原文直引支撑（受引文分流约束）；推测明码标价（"我要先泼盆冷水""这句我不敢当铁证"）；
   **成组镜像细节**（第一组/第二组/第三组）而非排比；概念辨析；可设对照组；
   悬念链式管理（抛问可延迟整节回答，payoff 同句接续下一问）；
   **长距离因果扣**——前段埋一处不起眼的原文细节，隔三到五节回收并明说"这里我们回收前面那个扣"。
4. **后段·上价值收束**：一到两句点明本期素材本身的价值。
5. **结尾·回扣**：回扣开场原文或意象；金句须扣母题、意象已锚地。
6. **固定签名**：「那，以上，我是狐久，我们下期视频再见。」

# 五、考据纪律

- 四级标注：**官方明示 / 文本暗示 / 合理推测 / 二创补全**。推测必须显式泼冷水。
- 引用逐字、「」括起；人名有异文时标官方译名并顺带纠一句。
- 未核验内容标〔待核验〕。情感闭环不能建立在未核实的一句话上。
- **只有二手来源的高风险引文**：要么不用，要么当着观众面说"我没能核到出处"。
  藏着比说出来危险——考据号的信誉建立在自曝短板上。
- **未公开的解包/泄露情报**：不写成陈述句。**埋，不说破**——让画面和原文自己碰撞，
  口播一字不解释，最多加一句"我们最后还会回来"式钩子。
  零断言、官方怎么写都不打脸、主线上线后该段自动变考古现场。

# 六、自检清单

**A 组 · 语言（不过就不许交）**
1. **第一原则否决线五项全过？** 脚本实测，FAIL 即重写。
2. **每段出声念过？有没有需要换两次气的句子？**
3. **三条铁律归零？**（东西／叙述层"你"／对比模板句）
4. **听觉体检四项跑过？**（同形异音／一句一个陌生名／引文分流／默读）
5. 时长实测跑过？超时给了三选项和逐节字数表？

**B 组 · 内容**
6. 主题成立？落在主体性/思辨层？
7. 每个结论有原文兜底？推测泼了冷水？分级与〔待核验〕标清？
8. 顺着素材时间轴？每段能对上具体画面？没写不存在的画面？
9. 开头 3 秒抓人？成组镜像而非排比？有长距离因果扣并明说回收？
10. 结尾回扣开场？落了上价值收束？签名、锚点、素材清单齐？
11. 转场承接句补全因果？意象锚在实物上？删段后无悬空引线？

# 七、常见翻车点（按严重度）

1. **写成名词的中文。** 最严重、最难自查，教科书式欧化词表全部检测不出来。见第一原则。
2. **把"给眼睛看的考据文"当口播稿交。** 长定语引文照念、音译名连轰、同形异音没查。见第二原则。
3. **把推测当官方。** 考据事故。
4. **叙述层用"你"／满篇"东西"／对比模板句。** 见第三原则。
5. **自检数字凭感觉估算。** 用户会当场跑脚本核出来，比不写自检更伤信任。
6. **时长按总字数估算。** 把 29 分钟报成 20 分钟，害用户剪到一半返工。
7. 排比堆情绪、密度掉下去；主题停在"好强/好惨"。
8. 金句空泛不扣母题；忘了回扣或签名。
9. 写了素材里没有的画面，成片无画可配。
10. 转场电报腔；开场意象悬空指代。
11. 硬概念只给定义没落到玩家经验。
12. 删段后留下悬空引线。
