# 音频权威与发布

## 正典与代理

`canonical_text` 是观众最终应当听到的文字；`generation_text` 只解决合成器读音。ASR 与 alias 都是诊断工具，不能改变官方专名。

机器词面检查允许两种结论：完全匹配，或存在由第二识别器/定点人工试听明确裁决的识别歧义。alias 必须逐条写入绑定当前 canonical/ASR SHA 的证据收据，记录证据类型、引用、审核人、时间和 `recognition_ambiguity` 结论；不得用宽泛替换 map 把真正的错字、多字或漏字洗成 PASS。

## 任何修改都会失效

再生成、替词拼接、接缝修复、触及语音的淡化、响度标准化和重新装配都会改变母带权威。实际输出必须重新计算 SHA，并重新完成全文词面、接缝和信号检查。母带变化以后，旧人工试听批准也随之失效。

## 状态含义

- `machine_verified`：实际母带的机器检查通过；
- `awaiting_human_audition`：等待完整 1× 人工试听，不能交给最终字幕；
- `released`：机器检查通过，人工批准绑定同一母带 SHA；
- `repair_required`：有未解决问题，必须修复并重新检查。

`audio_manifest.json` 保存机器权威和状态历史；`voice_release.json` 保存用户或授权审听人的审批引用、审听时间和已批准母带 SHA。只有两者一致时 `release_ready=true`。

## 最小机器检查

实际母带必须完成：完整解码、格式一致、合理时长、响度与峰值、全文顺序覆盖、零未解释插入/替换/删除、专名热点、最后一句与最后一字、全部接缝边界。单独片段通过不能代替母带通过。
