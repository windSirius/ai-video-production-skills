# 封面制作与人物保真

## 目录

1. 题眼
2. 来源冻结
3. 构图
4. 生成模型边界
5. 多画幅
6. 验收

## 1. 题眼

先写一句封面承诺：观众一眼要认出谁/什么，以及本期提出什么问题。主体控制在一至两个视觉中心；四人群像、神之心等多元素必须组成清楚的主次，而不是平均分格。

## 2. 来源冻结

对人物、道具、标志和官方模型建立 `cover_sources.json`：

```text
asset_id
canonical_identity
source_path
source_sha256
source_kind
allowed_transform
crop_note
review_status
```

`allowed_transform` 默认只允许裁切、缩放、旋转、遮罩、色彩统一、辉光和背景分离。任何会重绘五官、手部、服装纹样或官方道具结构的处理都需要用户另行批准。

## 3. 构图

- 优先让官方图承担角色识别，让生成或抽象图只承担背景、光效和氛围。
- 文案用本地字体排版，不让图像模型生成汉字。
- 在缩略图尺寸先检查主体和标题，再看大图细节。
- 边框、发光、分区和小图只服务层级；不能用装饰掩盖主体太小。

## 4. 生成模型边界

- 官方角色已有清晰图时，不让生成模型重新画角色。
- 需要新背景时，可以只生成不含人物、文字和官方模型的背景，再确定性合成源图。
- 如果用户明确要求风格化角色，先单独产出人物测试图并审核，不直接生成完整封面。
- 脸、眼睛、手、服装结构、剪影身份或官方模型出现崩坏，立即失败并回到源图合成。

## 5. 多画幅

分别设计 `16:9`、`4:3`、`3:4`。允许共享源图和视觉主题，但每个画幅重新安排主体、标题和安全区。不得只从16:9中间裁成3:4，导致人物、标志或标题被截。

## 6. 验收

逐项检查：

- 输出尺寸与色彩模式正确；
- 每个官方人物能与源图一眼对应；
- 神之心、武器、图标等模型没有重构或串形；
- 标题字没有错字、断字或模型伪字；
- 缩到平台列表大小仍能读题眼；
- 不含临时水印、审核提示、占位框或误导性来源；
- 每个画幅单独通过，不用一个版本替另一个背书。

保存通过版、源图、合成工程、来源清单和被淘汰版。不要覆盖唯一可回退成品。
