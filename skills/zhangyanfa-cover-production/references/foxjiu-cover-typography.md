# 狐久「障眼法考据」书页封面

用户澄清：“新青年体没有问题”，「障眼法考据 like」是**整体画面要有模拟书页的质感**。保留文悦新青年体，通过更清晰的颜色、文字构造和书页设计强化考据氛围。不要再将该要求解释为宋体、大字配细线，或仅在截图上加一个“考据”标签。

## 整体书页设计

- 先搭建可感知的纸面：纸纤维与细微旧痕、边缘厚度、卷角、撕边、书脊或页层。选两三项服务本版构图，不要将所有装饰堆在一起。
- 纸张必须是承载图文的主要版面，而不是贴在游戏截图角落的小装饰。主体、标题、页边距和图版要像同一页研究材料。默认使用已确认的 P2 撕页考据手账；单页或古书跨页留作用户要求换方向时的备选。保持纸面语言，每期重新设计人物关系与标题。
- 用户给的低分辨率纸张示例仅作材质与形态参考；不要放大像素或把透明棋盘格抄进画面。可用 ImageGen 生成没有中文、人物、符号的高清纸张背景，再用原生游戏资产和本地文字层组版。
- 游戏人物、衣饰、眼神和动作保留官方原生来源。照片图版可以裁切、等比缩放、加纸边或轻微印刷质感，不能为纸页氛围重画角色或伪造游戏证据。
- 自然纤维与适度老化即可。避免污渍压住字、焦黑重边、脏黄糊面；装饰印记不能冒充官方证据、游戏内印章或已核实资料。

## 字体、颜色与文字构造

- 主标题保留 **文悦新青年体 J W8**。确认实际字体文件与字形；不要因“书页/考据”自行改成宋体。小字可用简体黑体，通常不超过两个字体族。
- 全部文案简体，专名和问号完整。中文由本地字体排版，不让图像模型生成中文。
- 浅纸面优先用深墨色正文与鲜明朱红题眼；也可用深红色纸签搭配暖白字。颜色必须在实际纹理上清晰，允许为点击重点提高饱和度，不把“克制”理解为低对比灰金。
- 先确定题眼，再做字号与分组。可分成前提、动作、核心疑问，也可让关键词跨行、落在纸签上或形成一组大字。不要把每行做成同等分量，也不要机械沿用上一期的三行标题。
- 保留推测语气，标题与口播核心问题一致。本期“龙王？”可以最大，但下一期应重新选题眼。
- 不以描边、重阴影补救浅字叠亮背景；先移动文字、提高墨色对比或改变纸面明度。脸部、眼神和关键动作避开文字。

## 已确认的默认样式：P2 撕页考据手账

用户在三套纸页风格中选择 P2，查看三种画幅后明确要求“保留这个设计，把这个迭代进skill”。后续狐久封面以此为默认视觉规范。开始设计时实际打开下列样例，避免仅凭“书页感”的文字描述重新猜风格。

| 画幅 | 已确认的布局方法 | 视觉样例 |
| --- | --- | --- |
| 16:9，2560×1440 | 左侧浅纸承载标题、右侧暖纸放人物；竖向撕边分区；关键词分两行错位，疑问置于下方红纸签。 | [横版样例](../assets/foxjiu-paper-notebook/16_9.png) |
| 4:3，2400×1800 | 继续左右分区，拉开标题的纵向层级，右侧人物图版更修长；纸签仍在左下。 | [4:3 样例](../assets/foxjiu-paper-notebook/4_3.png) |
| 3:4，1800×2400 | 上方人物、下方浅纸标题；撕边改为横向；短核心标题尽量合为一行，下接宽版红纸签。 | [3:4 样例](../assets/foxjiu-paper-notebook/3_4.png) |

- 保留文悦新青年体 J W8。深墨 `#241d1a` 表达前提，朱红 `#b32622` 突出冲突或题眼，红纸签上用暖白 `#fff0d2`；小字可用 `#665142`。颜色随纸面明度微调，优先保证小图对比。
- 暖色纸底、浅色撕页、纸纤维、装订孔、少量胶带或卷角共同建立手账感。人物作为贴入的原生游戏图版，留浅色纸边、轻微投影，可旋转约 2–3°；角色本身保持等比。
- 纸签只承载一个核心疑问；样例里的“不死诅咒”“封住龙王？”是当期文案，不是以后照抄的固定标题。标题过长先精简分组，避免为塞满一行而缩成小字。
- 相同材质与色彩属于系列识别。六稿仍须有不同的叙事镜头或视觉命题；不能将六种排字充作六个叙事方案，也不应每期都用同一个人物近景。
- 多画幅必须分别布局：保留人物关键部位、调整撕边方向、照片形状与文字行列。禁止将整张 16:9 拉伸或中心裁切当作其他比例。
- [配置文件](../assets/foxjiu-cover-style.json)中的归一化坐标是起点，不是每期强行套用的像素模板。新项目复制样式快照后再按本期人物、文案和实际缩略图校正；不得改写旧期冻结配置。

样例仅用于视觉参照，来源说明随样例保存；不附字体文件，也不把样例人物素材视为每期已清权资产。

## 硬流程与验收

1. 读取本期已选叙事方向及用户参考，先明确纸面形态、图版位置、标题结构和色彩职责。
2. 用户要求重新探索风格时，先出可比较的横版方案；不把若干排字变体冒充六种新的叙事概念，不在方向未定时批量衍生其他画幅。
3. 生成背景、放入原生人物图版、添加本地文字。先检查无字构图能否读出真实纸页，再检查完整图的题眼和人物。
4. 逐张查看实际最终 PNG，以及 320px 和 640px 预览。320px 能辨认纸页和主体，读出核心标题；细纸纹可以弱化，卷角/页边/书脊至少仍有可见形态。
5. 主标题至少留约 3.5% 画布安全区；确认没有缺字、裁字、糊边、假透明底，人物等比且没有脸部遮挡。
6. 本期版本保存样式快照、字体 SHA、文案、文字边界、来源与排版操作，绑定这些本期快照，而不是绑定后续还会修改的全局 skill 配置文件。
7. 方向确定后再分别重排 16:9、4:3、3:4，保持纸面语言，每版独立调整人物、纸页结构和标题位置。新像素必须实际展示后才记录审批。

设计参数见 [foxjiu-cover-style.json](../assets/foxjiu-cover-style.json)。本规则修正了此前由助手误解产生的宋体默认方向；不得把那一版写成用户偏好或已接受的视觉标准。正式视频、B/C 卡片及旧期已批准产物不因本次修订而改变。
